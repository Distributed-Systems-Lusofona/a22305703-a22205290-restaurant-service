# Restaurant Service

This repository contains the Restaurant Service, one of the microservices in the Store (WE CHOSE TO KEEP THAT NAME CAUSE' IT DOES MAKE SENSE) Project —
a distributed system composed of multiple Spring Boot services that work together to manage an online store, or business in this particular case, a restaurant business to be, more precise.

Each microservice runs in its own container, communicating with others via REST APIs.
